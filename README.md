# Префлоп-тренажёр (Android / PWA)

Мобильный тренажёр префлоп-диапазонов: 33 спота, сетки 13×13, тренировка с проверкой ответов,
статистика ошибок (хранится в телефоне) и экран «мои факты» против чарта.

## Как установить на Android
1. Открыть страницу в Chrome.
2. Меню ⋮ → **Установить приложение** (или «Добавить на главный экран»).
3. Появится иконка, приложение работает с домашнего экрана, в том числе **без интернета**.

## Как обновлять
Правки в файлах → `git push` → страница обновится сама (service worker подтянет новую версию).

## Файлы
- `index.html`, `styles.css`, `app.js` — интерфейс; `logic.js` — чистая логика (сетка, диапазоны, допустимые ответы);
- `ranges.js` — данные чартов; `manifest.webmanifest`, `sw.js`, `icon-*.png` — установка и офлайн;
- `test-logic.js` — проверки логики: `node test-logic.js` (11 проверок).

## Происхождение данных и оговорки
Диапазоны взяты из открытого префлоп-тренажёра **EyeSeeEm/poker-trainer-preflop** (`src/rangeData.js`) —
это ручная разметка автора под типы соперников (Aggro/Passive/Pro/Fish), **не выгрузка солвера и без частот**.
Использование — личное, для тренировки. Перед публичным распространением стоит уточнить условия у автора исходного проекта.
Цифры на экране «мои факты» посчитаны по 18 775 раздачам PokerOK ($0.01/$0.02, 6-max); размер выборок разный,
сравнение ориентировочное.
